# shook-shi

모션 인식 기반의 투두리스트 스시 게임 웹입니다. 오늘의 할 일을 입력한 뒤, 대각선으로 날아오는 스시 투두를 먹거나 피하면서 마음속 우선순위를 정리합니다.

## 실행

빌드 과정이 없는 단일 HTML 프로젝트입니다. CSS와 앱 JavaScript는 모두 `index.html` 안에 포함되어 있습니다. 얼굴 인식은 브라우저에서 MediaPipe Tasks Vision CDN을 불러와 실행합니다.

1. `index.html`을 브라우저로 엽니다.
2. 할 일을 추가합니다.
3. 게임을 시작하고 `모션 켜기`를 누릅니다.
4. 입을 벌리면 먹기, 고개를 스시가 출발한 쪽으로 흔들면 피하기로 처리됩니다.

키보드 조작도 지원합니다.

- `←`, `→`: 좌우 이동 및 피하기
- `↑`, `Space`: 먹기
